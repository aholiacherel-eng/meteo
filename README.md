
# 🌤️ Mini Application Météo

Une mini application web permettant de rechercher la météo actuelle d'une ville en utilisant l’API OpenWeatherMap.



## 🚀 Fonctionnalités

* 🔍 Recherche de météo par nom de ville
* 🌡️ Affichage de la température en °C
* 🌥️ Description des conditions météo
* 💧 Taux d’humidité
* 💨 Vitesse du vent
* 🖼️ Icône météo dynamique
* 🎨 Interface moderne et responsive
* ⚠️ Gestion des erreurs (ville non trouvée)



## 🛠️ Technologies utilisées

* HTML5
* CSS3 (animations + responsive design)
* JavaScript (Fetch API, Async/Await)
* API OpenWeatherMap



## 🔑 API utilisée

OpenWeatherMap
[https://openweathermap.org/api](https://openweathermap.org/api)



## 📦 Installation

1. Cloner ou télécharger le projet
2. Ouvrir le fichier `index.html` dans un navigateur
3. Remplacer la clé API dans `script.js` :

```javascript
const API_KEY = 'VOTRE_CLE_API';
```



## 📁 Structure du projet

```
/projet-meteo
│── index.html
│── style.css
│── script.js
```


## ⚠️ Remarque importante

Pour un projet en production, il est recommandé de **ne pas exposer la clé API côté frontend**.
Une solution backend (Node.js, Django, etc.) est préférable pour sécuriser la clé.
